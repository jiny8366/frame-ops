파트 2. 의료기사법·의료관계법규

이것만 알아도 절반

  1. 안경사 업무: 안경 조제·판매, CL 판매, 약제 없는 굴절검사(타각적은 자동굴절검사기기만). 6세 이하는 의사 처방.
  2. 3년 이하 징역 또는 3천만 원 이하 벌금: 무면허 업무, 면허 대여·대여받기·알선, 비밀 누설(고소 있어야), 무면허자 안경업소 개설.
  3. 500만 원 이하 벌금: 명칭 사용, 2개 이상 개설, 미등록 개설, 온라인·통신판매, 업소 밖 판매, 영리 알선.
  4. 과태료는 형벌이 아니에요: 100만 원 이하(실태 허위 신고, 폐업·변경 미신고, 보고·검사 거부), 500만 원 이하(보수교육 위탁기관 시정명령 불이행).
  5. 행정처분: 6개월 이내 자격정지(품위손상 등), 등록취소 후 6개월 재개설 금지, 청문은 면허취소·등록취소.

파트 3. 기하광학·행렬

이것만 알아도 절반

  1. 단위: D = 1/m. 25 cm = 4 D, 33 cm ≈ 3 D, 40 cm = 2.5 D, 50 cm = 2 D.
  2. 얇은 렌즈: L′ = L + F (물체가 앞에 있으면 L은 −). 배율 m = L/L′ (음수면 도립).
  3. 두 렌즈: F = F₁ + F₂ − dF₁F₂ (d는 m). 간격이 작으면 F₁ + F₂로 어림.
  4. 프리즘: 광선은 기저 쪽으로 꺾이고, 상은 꼭지점 쪽으로 보여요. 1Δ = 1 m 앞에서 1 cm.
  5. 볼록렌즈는 실패형(핀쿠션) 왜곡, 오목렌즈는 술통형 왜곡.

버전스와 단위 바꾸기

★★★ 기본
용어 풀이 버전스 = 빛이 모이거나 퍼지는 정도. 모이면 +, 퍼지면 −. 값 = 1 ÷ 거리(m).
필수 암기 cm → D: 100 ÷ cm · mm → m: ÷ 1000 · 물체가 렌즈 앞 x cm면 L = −100/x
자주 하는 실수 50 cm를 0.5가 아니라 50으로 넣기, 앞쪽 거리의 − 부호 빼먹기.

얇은 렌즈의 상

★★★ 기본

예) +5.00 D 렌즈 앞 50 cm 물체: L = −2.00 D → L′ = −2 + 5 = +3.00 D → 상은 렌즈 뒤 33 cm(실상). m = −2/+3 = −0.67 → 도립·축소.

물체 위치(볼록렌즈)상

반사·굴절·구면

★★☆ 기본
  • 스넬 법칙: n₁ sin θ₁ = n₂ sin θ₂. 임계각: sin θc = n₂/n₁ (밀한 → 소한 매질일 때만).
  • 구면 굴절면: F = (n₂ − n₁)/r. 렌즈 제작자 공식(공기 중 얇은 렌즈): F = (n − 1)(1/r₁ − 1/r₂).
  • 구면 거울: 초점거리 = r/2. 평면거울 상은 같은 크기·정립·허상, 거울 뒤 같은 거리.

프리즘 기초

★★★ 기본
  • 얇은 프리즘 편위각 δ ≈ (n − 1)A. 프리즘 디옵터: 1 m 앞에서 1 cm 옮겨지면 1Δ.
  • 광선은 기저 쪽으로, 상(보이는 위치)은 꼭지점 쪽으로.
  • 분산: 파장마다 굴절률이 달라 색이 갈라짐. 아베수가 클수록 색 번짐이 적어요.

핵심 정리: 기하광학

★★☆ 기본
굴절률·스넬 법칙
n = c/v. n₁ sin θ₁ = n₂ sin θ₂. 임계각 sin θ_c = n₂/n₁ (밀 → 소 매질). n = 1.5 → θ_c ≈ 41.8°. 응용: 광섬유, 전반사 프리즘.
버전스 공식
V = U + F (U = n/u, V = n′/v, 거리는 렌즈 기준 부호: 빛 진행 방향 +). 횡배율 m = U/V (공기 중 = v/u). 실물체는 U < 0. 결과 V > 0 → 실상, V < 0 → 허상.
구면 굴절·거울
구면 굴절력 F = (n₂ − n₁)/r. 구면거울 f = r/2, 1/u + 1/v = 1/f(실제 거리 부호 규약에 주의), 평면거울 2개 사이각 θ → 상의 수 = 360/θ − 1.
렌즈 합성
밀착: F = F₁ + F₂. 분리: F_e = F₁ + F₂ − (d/n)F₁F₂. 두꺼운 렌즈 후면정점굴절력 F_v′ = F₁/(1 − (t/n)F₁) + F₂.
프리즘
얇은 프리즘 편향각 δ = (n − 1)A. 프리즘 디옵터 P = 100 tan δ (45° = 100 Δ). 분산: 단파장(보라)일수록 굴절률이 커서 많이 꺾인다.
조리개·수차
개구조리개 → 입사동(물체 공간 상)·사출동. 시야조리개 → 시야 제한. 단색수차(자이델 5수차): 구면수차·코마·비점수차·상면만곡·왜곡. 색수차: 종색수차 = F/ν, 횡색수차 = P/ν.

파트 4. 물리광학

이것만 알아도 절반

  1. 굴절률 n = c/v. 매질 속 파장 = λ/n, 진동수는 그대로.
  2. 반사 방지 코팅: 두께 λ/(4n막), 이상적 굴절률 n막 = √n렌즈 → 두 반사광이 상쇄.
  3. 편광: 물·도로 반사광은 수평 편광 → 편광렌즈 투과축은 수직. I = I₀ cos²θ.
  4. 회절: 구멍이 작을수록, 파장이 길수록 크게 퍼져요. 해상 한계 각 ≈ 1.22λ/D.
  5. 산란(레일리) ∝ 1/λ⁴ → 하늘이 파란 이유.

파동의 성질

★★☆ 기본
  • v = fλ. 빛이 밀한 매질로 들어가면 속도·파장이 줄고 진동수는 같아요.
  • 가시광선 약 380~780 nm. 짧은 쪽(보라·파랑)이 더 많이 굴절·산란.

간섭과 반사 방지 코팅

★★★ 기본
필수 암기 막 두께 = λ/(4n막) · 이상적 n막 = √n렌즈 · 반사 두 줄기의 경로차 = λ/2 → 상쇄
배경 렌즈 표면 반사가 줄면 투과율이 오르고, 야간 빛 번짐과 고스트 이미지가 줄어요.

회절

★★☆ 응용
  • 빛이 좁은 틈이나 가장자리를 지나며 퍼지는 현상. 틈이 작고 파장이 길수록 커요.
  • 원형 구멍: 에어리 원반, 해상 한계 각 θ ≈ 1.22λ/D. 동공이 너무 작으면 회절로 선명도가 떨어져요.

편광 (눈부심 줄이기)

★★★ 기본
  • 말뤼스 법칙: I = I₀ cos²θ. 두 편광판이 수직이면 거의 차단.

간섭

산란·레이저

파트 5. 안경광학·누진·프리즘

이것만 알아도 절반

  1. 프렌티스: Δ = c(cm) × F(D). 볼록렌즈는 기저가 광학중심 쪽, 오목렌즈는 반대쪽.
  2. 정점간거리: Fc = F/(1 − dF). 근시는 CL이 약해지고 원시는 강해져요. ±4 D 이상이면 꼭 계산.
  3. 구면등가 = S + C/2. 원주 표기 바꾸기: S′ = S + C, C′ = −C, 축 ± 90°.
  4. 방사선시표: 선명한 선의 작은 시 숫자 × 30° = (−)원주 축.
  5. 프리즘 조제: c = Δ / F(그 방향 경선 도수). (−)렌즈 BI → 광학중심을 바깥으로, BO → 안으로.

프렌티스 법칙: 닮은 삼각형으로 이해하기

★★★ 기본

렌즈 중심에서 c만큼 떨어진 곳으로 들어온 빛은 초점(거리 f = 1/F)을 지나요. 「높이 c, 밑변 f」 삼각형이 생기고, 빛이 꺾인 정도는 c ÷ f = c × F. 프리즘 디옵터는 「100 cm 앞에서 몇 cm 옮겨지나」라서 100 × c(m) × F = c(cm) × F 가 돼요.

필수 암기 Δ = c(cm) × F · 볼록(+)렌즈: 기저 = 광학중심 쪽 · 오목(−)렌즈: 기저 = 광학중심 반대쪽
자주 하는 실수 mm를 cm로 안 바꿈(10 mm = 1 cm) · 오목렌즈의 기저 방향을 볼록렌즈처럼 판단.

프렌티스 실제 상황 4가지

★★★ 기본
① PD를 잘못 맞춤 −4.00 D 렌즈의 광학중심을 한쪽 눈마다 3 mm씩 바깥으로 잘못 둠 → 한쪽 0.3 × 4 = 1.2Δ, 두 눈 합 2.4Δ (오목렌즈이므로 기저 안쪽, BI). 어지럼·피로의 원인.
② 안경이 코 아래로 흘러내림
③ 짝눈의 위아래 불균형
④ 일부러 옮기기(편심) +4.00 D 렌즈로 2Δ가 필요하면 2 ÷ 4 = 0.5 cm = 5 mm 옮겨요. 볼록렌즈는 원하는 기저 방향으로, 오목렌즈는 반대 방향으로 광학중심을 옮겨요.

정점간거리

★★★ 기본
정식 +10.00 D, 12 mm → CL
10 ÷ (1 − 0.012 × 10) ≈ 11.36 D
간편 F + dF² = 10 + 0.012 × 100 = 11.20 D
오차 약 0.16 D(1.4%). 보기가 0.25 D 간격이면 정식으로.

가입도·누진·이중초점

★★★ 기본
  • 가입도(Add) = 작업거리에 필요한 조절(예: 40 cm → 2.50 D) − 쓸 수 있는 조절(보통 조절력의 1/2을 남겨 둠).
  • Hofstetter 조절력: 최소 15 − 0.25×나이, 평균 18.5 − 0.3×나이, 최대 25 − 0.4×나이.
  • 누진렌즈: 원용부 → 누진대 → 근용부, 양옆에 비점수차 구역. 피팅 포인트를 동공 중심에 맞춰요.
  • 이중초점 상 뜀(image jump) = 분절 광학중심~분절선 거리(cm) × Add.
필수 암기 예) 50세 평균 조절력 18.5 − 15 = 3.5 D → 40 cm(2.5 D) 작업, 절반(1.75 D) 남기면 Add = 2.50 − 1.75 = +0.75 D

핵심 정리: 안경광학

★★☆ 기본
정점간거리 보정
새 위치의 굴절력 F_c = F / (1 − dF) (d: 렌즈를 눈 쪽으로 옮긴 거리[m], 안경 → CL이면 d = 정점간거리). 예: −8.00 D @12 mm → −8/(1+0.096) = −7.30 D, +10.00 D @13 mm → +11.49 D. ±4.00 D 미만은 보정 차이 미미.
원점 굴절과 교정
원점 거리 r(눈 기준) → 안경 굴절력 F = 1/(r − d) (부호 포함, m). 원점 25 cm 근시, 정점간거리 12 mm → F = −1/0.238 = −4.20 D.
프렌티스 법칙
P(Δ) = c(cm) × F(D). 플러스 렌즈: 기저는 광학중심 쪽 / 마이너스 렌즈: 기저는 광학중심 반대쪽. 1 Δ = 1 m에서 1 cm 편위.
생략안
굴절력 +60 D, n′ = 4/3, 전초점거리 1/60 = 16.67 mm, 후초점거리 n′/F = 22.2 mm. 축성 비정시를 전초점(각막 앞 약 15.7 mm, 굴스트란드 기준)에서 교정하면 상대배율 = 1 (냅의 법칙).
안경배율
SM = 도수인자 × 형태인자 = [1/(1 − hF)] × [1/(1 − (t/n)F₁)] (h: 렌즈 후면 ~ 입사동 거리). 플러스 → 확대, 마이너스 → 축소. 부등시 → 부등상시.
근용안경
가입도 Add = 1/작업거리 − (사용 가능 조절력, 흔히 조절력의 1/2). 명시역: 원점 = 1/Add(원용 정시 가정), 근점 = 1/(Add + A).
시야·저시력
플러스 고도 렌즈 → 환상암점(ring scotoma), 마이너스 → 환상복시. 확대경 배율 M = F/4 (명시거리 25 cm). 갈릴레이 망원경 M = −F_e/F_o, 경통 길이 = f_o + f_e.
비점수차·카파각
사입사 비점수차: 광축 밖 경사 광선 → 최적형(베스트폼) 렌즈 설계로 감소. 카파각: 동공중심선과 시축 사이 각 — 양(+)이면 각막반사가 비측으로 → 가성외사시.

안경테

핵심 정리: 안경조제가공

★★☆ 기본
처방 변환
구면-원주 전환(transposition): 새 S = S + C, 새 C = −C, 새 축 = 축 ± 90°. 토릭 변환: 기준곡면(BC)을 정하고 전면 구면 커브 = (축 방향 굴절력) − BC, 교차커브 = BC + C.
박스법
A: 렌즈 수평 폭, B: 수직 높이, DBL: 렌즈 간 거리, FPD(기준점간거리) = A + DBL. 단안 수평 편위량 = (FPD − PD)/2. 유효직경 ED. 최소 렌즈(블랭크) 직경 ≈ ED + 2 × 편위량 + 여유(약 2 mm).
프리즘 조제
편위량 c(cm) = P/F (해당 경선의 굴절력 사용). 플러스 렌즈: 기저 방향으로 광학중심 이동 / 마이너스 렌즈: 기저 반대 방향으로 이동. 예: (−) 렌즈 BI → 광학중심 이측 이동(조제 PD 증가).
피팅
정점간거리 보통 약 12 mm 전후. 전경각(범위 약 8~12°): 전경각 2°마다 광학중심을 동공 중심보다 약 1 mm 낮춤. 안면각(랩) 보정. 코받침·템플 조정, 렌즈 하단 볼 접촉 방지.
다초점
이중초점 분절 상단: 대체로 아래눈꺼풀 가장자리 높이. 누진렌즈: 단안 PD와 피팅 높이(동공 중심) 측정, 피팅 포인트를 동공 중심에, 가입도는 숨은 각인으로 확인. 렌즈미터로 가입도 = 근용부 전면정점굴절력 − 원용부 전면정점굴절력.
점검
렌즈미터로 구면·원주·축·프리즘·광학중심 확인, 축 오차 허용범위 관련 규격 확인. 축 오차 θ에 의한 잔여 원주 ≈ 2C sin θ (같은 크기 원주가 θ만큼 어긋날 때).
수직 프리즘
좌우 광학중심 높이 차 → 수직 불균형 프리즘 = 높이 차(cm) × 해당 수직경선 굴절력. 수직 융합여력이 작아 작은 값도 불편 유발.

핵심 정리: 굴절검사

★★☆ 기본

섬모체 비색소상피에서 생성 → 후방 → 동공 → 전방 → 전방각 섬유주 → 쉴렘관 → 집합관 → 상공막정맥(주경로). 보조 경로: 포도막공막 유출.
홍채·섬모체
동공괄약근: 부교감(동안신경, CN III) → 축동. 동공산대근: 교감 → 산동. 섬모체근 수축(부교감) → 섬모소대 이완 → 수정체 두꺼워짐 → 조절.
망막
원뿔세포(약 600~700만, 황반·중심와 집중, 명소시·색각), 막대세포(약 1억 2천만, 주변부, 암소시). 중심와: 원뿔세포만, 무혈관. 시신경유두: 시세포 없음 → 맹점. 외층(시세포)은 맥락막모세혈관, 내층은 망막중심동맥(안동맥 분지)이 영양.
외안근 6개
내직근·상직근·하직근·하사근: 동안신경(CN III) / 상사근: 활차신경(CN IV) / 외직근: 외전신경(CN VI) — 암기 'LR6 SO4, 나머지 3'. 상사근 1차작용 내회선, 하사근 1차작용 외회선.
안와·눈꺼풀·눈물
안와 7개 뼈: 이마뼈(전두골)·나비뼈(접형골)·벌집뼈(사골)·눈물뼈(누골)·위턱뼈(상악골)·광대뼈(관골)·입천장뼈(구개골). 눈둘레근: 안면신경(CN VII), 눈꺼풀올림근: CN III, 뮐러근: 교감. 눈물 배출: 눈물점 → 눈물소관 → 눈물주머니 → 코눈물관 → 아래콧길(하비도).
유전
적록색각이상: X염색체 연관 열성 → 남성에서 흔함.

핵심 정리: 시기생리학(눈생리학)

★★☆ 기본
시력
소수시력 V = 1 / 최소분리각(분). 1.0 = 1′, 0.5 = 2′, 0.1 = 10′. Snellen 20/40 = 0.5. logMAR = log₁₀(MAR, 분): 1′ → 0.0, 2′ → 0.30, 10′ → 1.0.
시야

광각
명소시(원뿔세포) 최대 시감도 555 nm, 암소시(막대세포, 로돕신) 507 nm → 푸르킨예 현상(어두워지면 청록색이 상대적으로 밝게). 암순응: 원뿔세포 약 7~10분에 1차 평탄, 막대세포 포함 약 30분 이상.
색각
삼원색설(S·M·L 원뿔세포, 최대 흡수 약 420·530·560 nm). 제1색각이상(L, 적), 제2색각이상(M, 녹), 제3색각이상(S, 청).
조절
조절력 A = 1/근점거리 − 1/원점거리 (m, 부호 포함 버전스). Hofstetter: 최소 15 − 0.25×나이, 평균 18.5 − 0.3×나이, 최대 25 − 0.4×나이 (D).
근견반응·동공
근견반응 3요소: 조절·폭주·축동. 대광반사 경로: 망막 → 시신경 → 시삭 → 시개앞핵 → 에딩거-베스트팔핵 → 동안신경 → 섬모체신경절 → 동공괄약근. 아가일로버트슨 동공: 대광반사 소실·근견반응 보존. 호너증후군: 축동·경도 안검하수·무한증(교감). 상대구심동공장애(RAPD): 시신경 질환.
굴절이상
축성 근시(안축장 증가), 굴절성 근시(굴절력 증가). 안축 1 mm 차이 ≈ 약 3 D(생략안 기준 근사).

★★☆ 기본
시력장애 질환

충혈 관련
결막충혈(주변부 진함, 혈관 이동) vs 섬모체(모양)충혈(각막 주위 진함 — 각막염·포도막염·급성녹내장). 유행성각결막염: 아데노바이러스(8·19·37형 등), 전염성 강함. 알레르기결막염: 가려움·점액성 분비물.

핵심 정리: 시기능이상(양안시기능)

★★☆ 기본
양안시 3단계
동시시 → 융합 → 입체시. 감각 이상: 억제, 이상망막대응, 약시. 입체시 단위: 초(″) (예: 티트무스 40″).
안위 검사
가림검사: 한눈가림(cover-uncover) → 사시 판별, 교대가림 → 사위+사시 총편위, 프리즘가림검사로 정량. 마독스로드: 우안 앞 수평 막대 → 수직 선 → 수평 사위 측정. 선이 같은 쪽(동측성) = 내사위, 교차성 = 외사위. 폰 그레페법: 분리 프리즘(예: 6Δ BU) + 측정 프리즘.
AC/A
사위법(계산법): AC/A = PD(cm) + (Δn − Δf)/D_n (내편위 +, 외편위 −, D_n = 1/근거리[m]). 경사법(구배법): AC/A = 렌즈 추가에 따른 근거리 사위 변화량 / 렌즈 굴절력. 정상 약 3~5 Δ/D.
분석 기준
셰어드(Sheard): 보상 융합여력 ≥ 2 × 사위량, 필요 프리즘 P = (2/3)D − (1/3)R. 퍼시벌(Percival): 편안 시 점이 융합범위 중앙 1/3. 고정시차를 0으로 하는 프리즘 = 연합사위.
대표 이상
폭주부족: 근거리 외사위 큼, 폭주근점 멀어짐, 낮은 AC/A, BO 여력 부족 → 폭주 훈련 우선, 필요 시 BI. 폭주과다: 근거리 내사위, 높은 AC/A → 근용 플러스 가입. 개산과다: 원거리 외사위 > 근거리, 높은 AC/A. 개산부족: 원거리 내사위 > 근거리, 낮은 AC/A. 조절부족: 연령 기대 최소값(15 − 0.25×나이) 미만 → 근용 플러스.
프리즘 처방
외사위 → BI, 내사위 → BO, 우안 상사위 → 우안 BD(또는 좌안 BU), 양안에 나누어 처방.
감각기능 검사
워스 4점(적색 필터 우안·녹색 필터 좌안 관례): 4개 정상 융합, 2개(적) 좌안 억제, 3개(녹) 우안 억제, 5개 복시.

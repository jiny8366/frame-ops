파트 5. 안경광학·누진·프리즘

함께 보는 날: D4 · D5

이것만 알아도 절반

  1. 프렌티스: Δ = c(cm) × F(D). 볼록렌즈는 기저가 광학중심 쪽, 오목렌즈는 반대쪽.
  2. 정점간거리: Fc = F/(1 − dF). 근시는 CL이 약해지고 원시는 강해져요. ±4 D 이상이면 꼭 계산.
  3. 구면등가 = S + C/2. 원주 표기 바꾸기: S′ = S + C, C′ = −C, 축 ± 90°.
  4. 방사선시표: 선명한 선의 작은 시 숫자 × 30° = (−)원주 축.
  5. 프리즘 조제: c = Δ / F(그 방향 경선 도수). (−)렌즈 BI → 광학중심을 바깥으로, BO → 안으로.

프렌티스 법칙: 닮은 삼각형으로 이해하기

★★★ 기본

렌즈 중심에서 c만큼 떨어진 곳으로 들어온 빛은 초점(거리 f = 1/F)을 지나요. 「높이 c, 밑변 f」 삼각형이 생기고, 빛이 꺾인 정도는 c ÷ f = c × F. 프리즘 디옵터는 「100 cm 앞에서 몇 cm 옮겨지나」라서 100 × c(m) × F = c(cm) × F 가 돼요.

필수 암기 Δ = c(cm) × F · 볼록(+)렌즈: 기저 = 광학중심 쪽 · 오목(−)렌즈: 기저 = 광학중심 반대쪽
자주 하는 실수 mm를 cm로 안 바꿈(10 mm = 1 cm) · 오목렌즈의 기저 방향을 볼록렌즈처럼 판단.

프렌티스 실제 상황 4가지

★★★ 기본
① PD를 잘못 맞춤 −4.00 D 렌즈의 광학중심을 한쪽 눈마다 3 mm씩 바깥으로 잘못 둠 → 한쪽 0.3 × 4 = 1.2Δ, 두 눈 합 2.4Δ (오목렌즈이므로 기저 안쪽, BI). 어지럼·피로의 원인.
② 안경이 코 아래로 흘러내림
③ 짝눈의 위아래 불균형
④ 일부러 옮기기(편심) +4.00 D 렌즈로 2Δ가 필요하면 2 ÷ 4 = 0.5 cm = 5 mm 옮겨요. 볼록렌즈는 원하는 기저 방향으로, 오목렌즈는 반대 방향으로 광학중심을 옮겨요.

정점간거리

★★★ 기본
정식 +10.00 D, 12 mm → CL
10 ÷ (1 − 0.012 × 10) ≈ 11.36 D
간편 F + dF² = 10 + 0.012 × 100 = 11.20 D
오차 약 0.16 D(1.4%). 보기가 0.25 D 간격이면 정식으로.
자주 하는 실수 안경 → CL은 F/(1 − dF), CL → 안경은 F/(1 + dF). 방향을 반대로 쓰면 부호가 틀려요.

가입도·누진·이중초점

★★★ 기본
  • 가입도(Add) = 작업거리에 필요한 조절(예: 40 cm → 2.50 D) − 쓸 수 있는 조절(보통 조절력의 1/2을 남겨 둠).
  • Hofstetter 조절력: 최소 15 − 0.25×나이, 평균 18.5 − 0.3×나이, 최대 25 − 0.4×나이.
  • 누진렌즈: 원용부 → 누진대 → 근용부, 양옆에 비점수차 구역. 피팅 포인트를 동공 중심에 맞춰요.
  • 이중초점 상 뜀(image jump) = 분절 광학중심~분절선 거리(cm) × Add.
필수 암기 예) 50세 평균 조절력 18.5 − 15 = 3.5 D → 40 cm(2.5 D) 작업, 절반(1.75 D) 남기면 Add = 2.50 − 1.75 = +0.75 D

난시 표기·구면등가·사축 원주

★★☆ 응용
  • 원주 축 방향 경선의 굴절력 = S, 축과 수직 경선 = S + C.
  • 구면등가 = S + C/2. 표기 바꾸기: S −2.00 C −1.00 × 180 = S −3.00 C +1.00 × 90.
정식(행렬) S −2.00 C −1.50 × 45, 수평 8 mm 편심 → 수평 약 2.20Δ + 수직 약 0.60Δ
간편 수직 성분을 놓침 → 오차 0.60Δ. 축이 비스듬하면 정식으로.

프리즘 합성·분해

★★☆ 응용

두 눈에 나눠 처방할 때: 같은 종류의 기저(BI+BI, BO+BO)는 더하고, 상하는 한 눈 BU + 다른 눈 BD가 같은 효과예요.

배율·재료 (시간 남으면)

★☆☆ 심화
  • 안경배율 = 굴절력 인자 1/(1 − hF) × 형태 인자. 근시 안경은 작게, 원시 안경은 크게 보여요.
  • 재료: CR-39 n ≈ 1.50(아베수 약 58), 폴리카보네이트 n ≈ 1.59(아베수 약 30, 충격에 강함), 고굴절 1.60~1.74.

굴절검사 흐름

★★☆ 응용
  • 운무 → 방사선시표로 난시축 → 크로스실린더로 축·도수 정밀 → 적록검사(적색이 선명 → −추가, 녹색 → +추가) → MPMVA → 양안 조절 균형.

핵심 정리: 안경광학

★★☆ 기본
정점간거리 보정
새 위치의 굴절력 F_c = F / (1 − dF) (d: 렌즈를 눈 쪽으로 옮긴 거리[m], 안경 → CL이면 d = 정점간거리). 예: −8.00 D @12 mm → −8/(1+0.096) = −7.30 D, +10.00 D @13 mm → +11.49 D. ±4.00 D 미만은 보정 차이 미미.
원점 굴절과 교정
원점 거리 r(눈 기준) → 안경 굴절력 F = 1/(r − d) (부호 포함, m). 원점 25 cm 근시, 정점간거리 12 mm → F = −1/0.238 = −4.20 D.
프렌티스 법칙
P(Δ) = c(cm) × F(D). 플러스 렌즈: 기저는 광학중심 쪽 / 마이너스 렌즈: 기저는 광학중심 반대쪽. 1 Δ = 1 m에서 1 cm 편위.
생략안
굴절력 +60 D, n′ = 4/3, 전초점거리 1/60 = 16.67 mm, 후초점거리 n′/F = 22.2 mm. 축성 비정시를 전초점(각막 앞 약 15.7 mm, 굴스트란드 기준)에서 교정하면 상대배율 = 1 (냅의 법칙).
안경배율
SM = 도수인자 × 형태인자 = [1/(1 − hF)] × [1/(1 − (t/n)F₁)] (h: 렌즈 후면 ~ 입사동 거리). 플러스 → 확대, 마이너스 → 축소. 부등시 → 부등상시.
근용안경
가입도 Add = 1/작업거리 − (사용 가능 조절력, 흔히 조절력의 1/2). 명시역: 원점 = 1/Add(원용 정시 가정), 근점 = 1/(Add + A).
시야·저시력
플러스 고도 렌즈 → 환상암점(ring scotoma), 마이너스 → 환상복시. 확대경 배율 M = F/4 (명시거리 25 cm). 갈릴레이 망원경 M = −F_e/F_o, 경통 길이 = f_o + f_e.
비점수차·카파각
사입사 비점수차: 광축 밖 경사 광선 → 최적형(베스트폼) 렌즈 설계로 감소. 카파각: 동공중심선과 시축 사이 각 — 양(+)이면 각막반사가 비측으로 → 가성외사시.

핵심 정리: 안경재료학

★★☆ 기본
안경테
구성: 프런트(림·브리지·엔드피스), 코받침(패드·패드암), 경첩, 안경다리(템플·팁). 금속: 티타늄(가볍고 내식성·생체적합성 우수, 비자성, 용접 어려움), 니켈-티타늄 형상기억합금(탄성·복원), 모넬(니켈-구리, 니켈 알레르기 주의), 양은(구리-아연-니켈). 플라스틱: 셀룰로오스 아세테이트(가열 성형), 폴리아미드·TR-90 계열(가볍고 유연), 셀룰로이드(가연성).
렌즈 재료 지표
굴절률 n(높을수록 얇음), 아베수 ν = (n_d − 1)/(n_F − n_C)(낮을수록 색수차 큼), 비중, 내충격성, 반사율 R = ((n − 1)/(n + 1))² (한 면, 수직입사).
대표 재료(대략값)
크라운유리 n 1.523 / ν 약 59 · CR-39 n 약 1.50 / ν 약 58 / 비중 약 1.32 · 폴리카보네이트 n 약 1.59 / ν 약 30 (내충격성 최우수) · 고굴절 플라스틱 1.60~1.74 (ν 약 32~42).
다초점·누진
이중초점: 일자형(D형)·원형·E형(이그제큐티브). 상의 도약 = 분절 광학중심과 분절 상단 사이 거리 × 가입도(Prentice). E형·일자형은 분절 광학중심이 상단 근처여서 상 도약이 거의 없음. 누진렌즈: 원용부–누진대–근용부, 측방 비점수차 영역. 하드 디자인(명시역 넓음·수차 집중) vs 소프트 디자인(누진대 길고 수차 분산, 적응 쉬움).
기능성 렌즈
조광: 유리-할로겐화은, 플라스틱-유기 광변색 염료(자외선 반응, 저온에서 더 진해짐, 차 안에서는 반응 약함). 편광: 수평면 반사광(수평 편광 성분) 차단 — 투과축 수직. 자외선: UV-C 100~280, UV-B 280~315, UV-A 315~400 nm.
코팅
반사방지(AR): 박막 간섭, 막두께 λ/(4n_f), 이상적 단층 굴절률 n_f = √n_s. 하드코팅: 긁힘 방지. 발수·방오 코팅.

핵심 정리: 안경조제가공

★★☆ 기본
처방 변환
구면-원주 전환(transposition): 새 S = S + C, 새 C = −C, 새 축 = 축 ± 90°. 토릭 변환: 기준곡면(BC)을 정하고 전면 구면 커브 = (축 방향 굴절력) − BC, 교차커브 = BC + C.
박스법
A: 렌즈 수평 폭, B: 수직 높이, DBL: 렌즈 간 거리, FPD(기준점간거리) = A + DBL. 단안 수평 편위량 = (FPD − PD)/2. 유효직경 ED. 최소 렌즈(블랭크) 직경 ≈ ED + 2 × 편위량 + 여유(약 2 mm).
프리즘 조제
편위량 c(cm) = P/F (해당 경선의 굴절력 사용). 플러스 렌즈: 기저 방향으로 광학중심 이동 / 마이너스 렌즈: 기저 반대 방향으로 이동. 예: (−) 렌즈 BI → 광학중심 이측 이동(조제 PD 증가).
피팅
정점간거리 보통 약 12 mm 전후. 전경각(범위 약 8~12°): 전경각 2°마다 광학중심을 동공 중심보다 약 1 mm 낮춤. 안면각(랩) 보정. 코받침·템플 조정, 렌즈 하단 볼 접촉 방지.
다초점
이중초점 분절 상단: 대체로 아래눈꺼풀 가장자리 높이. 누진렌즈: 단안 PD와 피팅 높이(동공 중심) 측정, 피팅 포인트를 동공 중심에, 가입도는 숨은 각인으로 확인. 렌즈미터로 가입도 = 근용부 전면정점굴절력 − 원용부 전면정점굴절력.
점검
렌즈미터로 구면·원주·축·프리즘·광학중심 확인, 축 오차 허용범위 관련 규격 확인. 축 오차 θ에 의한 잔여 원주 ≈ 2C sin θ (같은 크기 원주가 θ만큼 어긋날 때).
수직 프리즘
좌우 광학중심 높이 차 → 수직 불균형 프리즘 = 높이 차(cm) × 해당 수직경선 굴절력. 수직 융합여력이 작아 작은 값도 불편 유발.

핵심 정리: 굴절검사

★★☆ 기본
검사 순서(예)
문진 → 예비검사(시력, 동공, 안위·안구운동, 폭주근점, 입체시·색각 등) → 타각적 굴절검사(검영법·자동굴절검사) → 자각적 굴절검사(운무 → 구면 MPMVA → 난시(방사선시표·JCC) → 구면 재정밀 → 양안조절균형) → 근용검사(가입도) → 처방.
원용 검사 원리
운무법: 플러스를 더해 인공 근시 상태로 조절을 이완. MPMVA: 최고 시력을 주는 최대 플러스(최소 마이너스). 적록검사: 적색 선명 → 마이너스 추가(−0.25), 녹색 선명 → 플러스 추가(+0.25).
난시 검사
방사선시표(운무 상태): 가장 선명한 선의 작은 시계 숫자 × 30 = (−)원주 축. JCC 축 정밀: 더 선명한 면의 (−)축(적색점) 쪽으로 축 이동. JCC 도수 정밀: (−)축이 원주 축과 일치할 때 선명 → (−)원주 추가. 원주 −0.50 D 변경 시 구면 +0.25 D 보정(등가구면 유지).
검영법
동행 → 플러스 추가, 역행 → 마이너스 추가, 중화점에서 반사 전체가 밝아짐. 작업거리 보정: 측정값 − 1/작업거리(m) (67 cm → −1.50 D, 50 cm → −2.00 D).
원시 분류
총원시 = 잠복원시 + 현성원시, 현성원시 = 수의원시 + 절대원시. 잠복원시는 조절마비 후 드러남(안경사는 약제 사용 불가).
난시 분류
직난시: 수직경선 굴절력이 더 강함 — (−)원주 축 180°±30°. 도난시: (−)원주 축 90°±30°. 사난시: 그 외. 단성·복성·혼합난시 구분은 두 주경선의 초선 위치로.
근용 검사
가입도: FCC(융합 교차원주)·MEM 검영·NRA/PRA 균형(가입도 + (NRA+PRA)/2) 등. 가입도는 '최소 필요량'으로 처방.
윤리

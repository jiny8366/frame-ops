파트 7. 안과학·양안시·안질환

함께 보는 날: D7 · D8

이것만 알아도 절반

  1. 외안근 신경: LR6 SO4, 나머지 3. 상사근 1차 작용은 내회선.
  2. 방수: 섬모체 → 뒷방 → 동공 → 앞방 → 섬유주 → 쉴렘관. 막히면 안압↑.
  3. 증상 → 질환: 갑작스러운 통증·충혈·무지개 달무리 = 급성폐쇄각녹내장(즉시 의뢰), 번쩍임·날파리·커튼 = 망막박리(즉시 의뢰).
  4. 가림-가림제거: 가렸던 눈이 바깥 → 안으로 움직이면 외사위(교정 BI), 안 → 바깥이면 내사위(교정 BO).
  5. Sheard: 보상 융합 여력 ≥ 사위량의 2배. Hofstetter 평균 조절력 18.5 − 0.3×나이.

눈 구조와 방수 흐름

★★★ 기본
  • 3층막: 섬유막(각막·공막) / 포도막(홍채·섬모체·맥락막) / 망막.
  • 각막 5층(상피–보우만층–실질–데스메막–내피). 내피는 거의 분열하지 않고 펌프로 투명성 유지.
  • 망막: 원뿔세포(황반, 색·밝은 곳), 막대세포(주변, 어두운 곳). 시신경유두 = 맹점.

외안근과 신경

★★★ 기본

시각 경로와 시야

★★☆ 응용

시신경 → 시교차 → 시삭 → 외측슬상체 → 시방선 → 후두엽. 시교차 병변(예: 뇌하수체 종양) → 양이측 반맹. 녹내장 → 활 모양 암점, 비측 계단.

양안시: 조절·폭주·사위

★★★ 기본
필수 암기 외사위 → BI, 내사위 → BO, 상사위 → 그 눈 BD · Sheard: 융합 여력 ≥ 2 × 사위 · Percival: 융합 범위의 가운데 1/3 · 마독스 교차성 복시 = 외편위
  • AC/A 비: 조절 1 D당 생기는 폭주량(Δ). 정상 약 3~5Δ/D. 높으면 근거리 내사위 경향.
  • 근점(조절): 나이가 들수록 멀어져요. 예) 평균 조절력 4 D → 근점 25 cm.

안질환 단원 바로가기

★★★ 기본

안질환은 따로 한 단원(사진·의뢰 기준·25문항 이상)으로 정리했어요 → 안질환 단원 열기

핵심 정리: 시기해부학(눈해부학)

★★☆ 기본
안구의 3층막
외막(섬유막): 각막·공막 / 중막(포도막): 홍채·섬모체(모양체)·맥락막 / 내막: 망막(10층). 안구 내용물: 수정체·방수·유리체.
각막
5층(상피–보우만층–실질–데스메막–내피). 상피는 재생, 보우만층은 손상 시 반흔. 내피는 성인에서 거의 분열하지 않으며 펌프 기능으로 각막 탈수(투명성)를 유지. 무혈관, 삼차신경(제1분지) 감각. 굴절력 약 +43 D로 눈 전체(약 +60 D)의 약 2/3.
방수 순환
섬모체 비색소상피에서 생성 → 후방 → 동공 → 전방 → 전방각 섬유주 → 쉴렘관 → 집합관 → 상공막정맥(주경로). 보조 경로: 포도막공막 유출.
홍채·섬모체
동공괄약근: 부교감(동안신경, CN III) → 축동. 동공산대근: 교감 → 산동. 섬모체근 수축(부교감) → 섬모소대 이완 → 수정체 두꺼워짐 → 조절.
망막
원뿔세포(약 600~700만, 황반·중심와 집중, 명소시·색각), 막대세포(약 1억 2천만, 주변부, 암소시). 중심와: 원뿔세포만, 무혈관. 시신경유두: 시세포 없음 → 맹점. 외층(시세포)은 맥락막모세혈관, 내층은 망막중심동맥(안동맥 분지)이 영양.
외안근 6개
내직근·상직근·하직근·하사근: 동안신경(CN III) / 상사근: 활차신경(CN IV) / 외직근: 외전신경(CN VI) — 암기 'LR6 SO4, 나머지 3'. 상사근 1차작용 내회선, 하사근 1차작용 외회선.
안와·눈꺼풀·눈물
안와 7개 뼈: 이마뼈(전두골)·나비뼈(접형골)·벌집뼈(사골)·눈물뼈(누골)·위턱뼈(상악골)·광대뼈(관골)·입천장뼈(구개골). 눈둘레근: 안면신경(CN VII), 눈꺼풀올림근: CN III, 뮐러근: 교감. 눈물 배출: 눈물점 → 눈물소관 → 눈물주머니 → 코눈물관 → 아래콧길(하비도).
유전
적록색각이상: X염색체 연관 열성 → 남성에서 흔함.

핵심 정리: 시기생리학(눈생리학)

★★☆ 기본
시력
소수시력 V = 1 / 최소분리각(분). 1.0 = 1′, 0.5 = 2′, 0.1 = 10′. Snellen 20/40 = 0.5. logMAR = log₁₀(MAR, 분): 1′ → 0.0, 2′ → 0.30, 10′ → 1.0.
시야
정상 단안 시야(대략): 이측 90~100°, 하측 약 70°, 비측 약 60°, 상측 약 50~60°. 생리적 맹점: 고시점 이측 약 12~17°, 수평선 약간 아래.
광각
명소시(원뿔세포) 최대 시감도 555 nm, 암소시(막대세포, 로돕신) 507 nm → 푸르킨예 현상(어두워지면 청록색이 상대적으로 밝게). 암순응: 원뿔세포 약 7~10분에 1차 평탄, 막대세포 포함 약 30분 이상.
색각
삼원색설(S·M·L 원뿔세포, 최대 흡수 약 420·530·560 nm). 제1색각이상(L, 적), 제2색각이상(M, 녹), 제3색각이상(S, 청).
조절
조절력 A = 1/근점거리 − 1/원점거리 (m, 부호 포함 버전스). Hofstetter: 최소 15 − 0.25×나이, 평균 18.5 − 0.3×나이, 최대 25 − 0.4×나이 (D).
근견반응·동공
근견반응 3요소: 조절·폭주·축동. 대광반사 경로: 망막 → 시신경 → 시삭 → 시개앞핵 → 에딩거-베스트팔핵 → 동안신경 → 섬모체신경절 → 동공괄약근. 아가일로버트슨 동공: 대광반사 소실·근견반응 보존. 호너증후군: 축동·경도 안검하수·무한증(교감). 상대구심동공장애(RAPD): 시신경 질환.
굴절이상
축성 근시(안축장 증가), 굴절성 근시(굴절력 증가). 안축 1 mm 차이 ≈ 약 3 D(생략안 기준 근사).

핵심 정리: 안질환

★★☆ 기본
시력장애 질환
백내장(연령관련이 가장 흔함, 수정체 혼탁), 당뇨망막병증(비증식: 미세동맥류·점상출혈·경성삼출 / 증식: 신생혈관·유리체출혈·견인망막박리), 연령관련 황반변성(건성: 드루젠·지도형위축 / 습성: 맥락막신생혈관; 변시증·중심암점, 암슬러격자), 망막박리(광시증·비문증·커튼 모양 시야가림).
충혈 관련
결막충혈(주변부 진함, 혈관 이동) vs 섬모체(모양)충혈(각막 주위 진함 — 각막염·포도막염·급성녹내장). 유행성각결막염: 아데노바이러스(8·19·37형 등), 전염성 강함. 알레르기결막염: 가려움·점액성 분비물.
통증 관련
각막염(세균·바이러스·진균·가시아메바), 공막염, 안와봉와직염. 가시아메바각막염: 수돗물·수영 + CL, 극심한 통증, 고리 모양 침윤, 방사상 각막신경염.
시야장애
녹내장: 진행성 시신경병증 + 특징적 시야결손(비측계단·궁상암점). 통계적 정상 안압 약 10~21 mmHg. 급성폐쇄각녹내장: 극심한 안통·두통·구역, 충혈, 각막부종(무지개 달무리), 중등도 산동 고정.
눈꺼풀·눈물
맥립종(다래끼): 급성 화농성, 통증 / 산립종(콩다래끼): 마이봄샘 만성 육아종성 염증, 무통성 결절. 건성안: 쉬르머 검사, 눈물막파괴시간(TBUT) 10초 미만이면 불안정.
CL 관련
거대유두결막염(GPC, 위눈꺼풀결막 유두), 저산소(미세낭포·각막부종·신생혈관), 3–9시 각막 착색(RGP), 미생물 각막염.
기타
원추각막: 각막 중심/하방 얇아짐·원뿔형 돌출, 불규칙 근시성 난시, 플라이셔 고리, 먼슨 징후, 보그트 선.

핵심 정리: 시기능이상(양안시기능)

★★☆ 기본
양안시 3단계
동시시 → 융합 → 입체시. 감각 이상: 억제, 이상망막대응, 약시. 입체시 단위: 초(″) (예: 티트무스 40″).
안위 검사
가림검사: 한눈가림(cover-uncover) → 사시 판별, 교대가림 → 사위+사시 총편위, 프리즘가림검사로 정량. 마독스로드: 우안 앞 수평 막대 → 수직 선 → 수평 사위 측정. 선이 같은 쪽(동측성) = 내사위, 교차성 = 외사위. 폰 그레페법: 분리 프리즘(예: 6Δ BU) + 측정 프리즘.
AC/A
사위법(계산법): AC/A = PD(cm) + (Δn − Δf)/D_n (내편위 +, 외편위 −, D_n = 1/근거리[m]). 경사법(구배법): AC/A = 렌즈 추가에 따른 근거리 사위 변화량 / 렌즈 굴절력. 정상 약 3~5 Δ/D.
분석 기준
셰어드(Sheard): 보상 융합여력 ≥ 2 × 사위량, 필요 프리즘 P = (2/3)D − (1/3)R. 퍼시벌(Percival): 편안 시 점이 융합범위 중앙 1/3. 고정시차를 0으로 하는 프리즘 = 연합사위.
대표 이상
폭주부족: 근거리 외사위 큼, 폭주근점 멀어짐, 낮은 AC/A, BO 여력 부족 → 폭주 훈련 우선, 필요 시 BI. 폭주과다: 근거리 내사위, 높은 AC/A → 근용 플러스 가입. 개산과다: 원거리 외사위 > 근거리, 높은 AC/A. 개산부족: 원거리 내사위 > 근거리, 낮은 AC/A. 조절부족: 연령 기대 최소값(15 − 0.25×나이) 미만 → 근용 플러스.
프리즘 처방
외사위 → BI, 내사위 → BO, 우안 상사위 → 우안 BD(또는 좌안 BU), 양안에 나누어 처방.
감각기능 검사
워스 4점(적색 필터 우안·녹색 필터 좌안 관례): 4개 정상 융합, 2개(적) 좌안 억제, 3개(녹) 우안 억제, 5개 복시.
